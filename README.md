# Hermes Mail Collector — public information

Static application information and privacy disclosures for a privately operated, read-only Gmail collector.

This repository contains **public documentation only**. It must never contain OAuth clients, tokens, mailbox addresses, messages, collector outputs, logs, or local configuration. The collector runs separately on the operator's machine.

- Home: `index.html`
- Privacy: `privacy.html`
- Styling: `style.css`
- Hosting: GitHub Pages, `main` branch root.

The Google OAuth publishing status and API collector deployment are separate from this documentation site. Publishing this site does not certify Google verification or complete the collector cutover.
